Web-Programmierung

Kopiere einfach den folgenden HTML-Code und füge ihn in den <body>-Bereich Deiner Webseite ein.

HTML
<!-- Newsbox -->
<div class="wrapper">
<table class="box" cellpadding="0" cellspacing="0">
<tr>
<td class="rahmen">
<div class="laufzeile">
<div class="laufzeile-text">✦ NEWS --- NEWS --- NEWS ✦</div>
</div>
<div id="inhalt">
✦Beispiel:<br /><br />
✿ Neue Tutorials in Arbeit<br />
✿ Bald: Download-Ecke<br />
✿ Feedback willkommen!<br /><br />

:•.DarkNickli wünscht Euch<br />
viel Spaß mit der Newsbox!.•:<br /><br />
<a target="_blank" href="#" class="Credits">Newsbox by DarkNickli</a>
</div>
</td>
</tr>
</table>
</div>
<!-- Newsbox End -->

Kopiere den Stil-Code in Deine CSS-Datei.
Du kannst die Farben anschließend an Dein Design anpassen.

Erklärung

１. Der äußere Rahmen (.box)

Das ist der Hauptbereich der Newsbox.

CSS
.box {
border: 8px solid #bddaf8;     /* Art, Dicke und Farbe des äußeren Rahmens */
width: 200px;                  /* Breite der Box */
height: 125px;                 /* Höhe der Box */
background: #7c85a1;           /* Hintergrundfarbe der Box */
color: #f5d3f8;                /* Grundfarbe für Text */
}

Anpassungen:
 border: → Legt Art, Dicke und Farbe des äußeren Rahmens fest.
Beispiel:

CSS
border: 4px dashed red;

→ Ein 4 Pixel breiter, gestrichelter roter Rahmen.
background: → Damit kannst Du die Hintergrundfarbe der Box ändern.
width/height → Damit bestimmst Du die Breite und Höhe der Newsbox.
Achte darauf, dass der Inhalt noch ausreichend Platz hat.

２. Der Innenrahmen (.rahmen)

Dieser Bereich liegt innerhalb der Box und erhält einen doppelten Rahmen sowie eine zusätzliche Umrandung (outline).

CSS
.rahmen {
border: 4px double #ffbec8;      /* Doppelrahmen in Rosa */
outline: 2px solid #ffbec8;      /* Äußere Umrandung */
outline-offset: 8px;             /* Abstand zwischen Rahmen und Outline */
padding: 0;                      /* Innenabstand */
}

Anpassungen:
 border: → Legt Art, Dicke und Farbe des Rahmens fest.
outline: → Fügt eine zusätzliche Umrandung außerhalb des Rahmens hinzu.
outline-offset: → Bestimmt den Abstand zwischen dem Rahmen (border) und der zusätzlichen Umrandung (outline).
padding: → Legt den Innenabstand des Elements fest.

３. Die Laufzeile (.laufzeile + .laufzeile-text)

Hier läuft der NEWS-Streifen oben durch die Newsbox.

CSS
.laufzeile {
width: 100%;                         /* Volle Breite des Containers */
overflow: hidden;                    /* Versteckt den überstehenden Inhalt */
white-space: nowrap;                 /* Text bleibt in einer Zeile */
border-bottom: 2px solid #ffbec8;    /* Untere Linie in zartem Rosa */
background: #bddaf8;                 /* Hellblaue Hintergrundfarbe */
color: #000;                         /* Schwarze Schriftfarbe */
font-weight: bold;                   /* Fett gedruckter Text */
font-size: 12px;                     /* Schriftgröße */
text-shadow: 0px 0px 5px #fff, 1px 1px 0px #fff; /* Weißer Leuchteffekt um den Text */
}

Anpassungen:
 width: → Bestimmt die Breite der Laufzeile.
overflow: hidden; → Versteckt den Teil des Textes, der außerhalb der Laufzeile liegt.
white-space: nowrap; → Verhindert einen Zeilenumbruch.
border-bottom: → Legt Farbe und Dicke der unteren Linie fest.
background: → Legt die Hintergrundfarbe der Laufzeile fest.
color: → Legt die Schriftfarbe fest.
text-shadow: → Erzeugt einen Leuchteffekt um die Schrift.
font-size: → Bestimmt die Größe der Laufschrift.

CSS
.laufzeile-text {
display: inline-block;                   /* Damit der Text animiert werden kann */
padding-left: 100%;                      /* Startet rechts außerhalb des sichtbaren Bereichs */
animation: laufband 12s linear infinite; /* Animation: 12 Sekunden, gleichmäßig und unendlich */
}

Anpassungen:
 animation: laufband 12s → Bestimmt die Laufgeschwindigkeit des Textes.
→ Kleinere Zahl = schneller
→ Größere Zahl = langsamer
Zum Beispiel:

CSS
animation: laufband 8s linear infinite;

→ Der Text läuft schneller durch die Newsbox.

４. Der Inhalt (id="inhalt")

Das ist der scrollbare Inhalt der Newsbox.

CSS
#inhalt {
text-align: center;          /* Text wird zentriert */
overflow: auto;              /* Scrollbalken bei Überlauf */
width: 200px;                /* Breite des Bereichs */
height: 125px;               /* Höhe des Bereichs */
color: #ffffff;              /* Weiße Schriftfarbe */
font-size: 11px;             /* Schriftgröße */
text-shadow: 1px 0px 5px #000, 1px 1px 0px #000; /* Schwarzer Schatten um den Text */
}

Anpassungen:
 text-align: → Bestimmt die Ausrichtung des Textes.
overflow: auto; → Erzeugt automatisch einen Scrollbalken, wenn der Inhalt nicht vollständig in den Bereich passt.
width: → Bestimmt die Breite des Inhaltsbereichs.
height: → Bestimmt die Höhe des Inhaltsbereichs.
color: → Legt die Schriftfarbe fest.
font-size: → Bestimmt die Schriftgröße.
text-shadow: → Erzeugt einen Schatteneffekt um die Schrift.

５. Die Quellenangabe (.Credits)

Das ist der Link ganz unten in der Newsbox, der die Quelle oder den Urheber zeigt.

CSS
.Credits {
font-size: 7pt;              /* Schriftgröße */
font-weight: lighter;        /* Dünnere Schrift */
color: #bddaf8;              /* Helle, blaue Linkfarbe */
text-decoration: none;       /* Kein Unterstrich */
}

.Credits:hover {
text-decoration: underline;  /* Unterstrich beim Überfahren mit der Maus */
}

Anpassungen:
 font-size: → Legt die Schriftgröße fest, z.B. größer oder kleiner.
font-weight: → Bestimmt die Schriftstärke.
color: → Legt die Farbe des Links fest.
text-decoration: → Legt fest, ob der Link unterstrichen wird.
.Credits:

CSS
text-decoration: none;

→ Normalerweise kein Unterstrich.

.Credits:hover:

CSS
text-decoration: underline;

→ Beim Überfahren mit der Maus erscheint der Unterstrich.
