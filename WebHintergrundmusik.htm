Web-Programmierung

HTML-Vorschau für Deine Audio-Datei

HTML
<audio controls autoplay loop>
<source src="musikdateiname.mp3" type="audio/mpeg">
</audio>

Erklärung

１. Gehe auf https://pixabay.com/music
２. Suche Dir eine Musik aus:
→ Ich habe „Birds and Waterfall“ gewählt.
３. Klicke auf „Download“
→ Du bekommst eine Datei, z. B. eine .mp3.
４. Lade die Datei auf Deine Webseite hoch.
→ Am besten in einen Ordner wie sounds/ oder audio/.

HTML
<audio controls autoplay loop>
<source src="musikdateiname.mp3" type="audio/mpeg">
</audio>

▸ controls zeigt die Steuerung an.
▸ autoplay versucht, die Datei automatisch zu starten.
▸ loop lässt die Musik wiederholen.

Hinweis:
autoplay wird von manchen Browsern blockiert.
Daher wird die Musik in diesem Fall nicht automatisch abgespielt.

Wichtig:
Der sichtbarer Player mit controls ist dafür genau richtig.
Wenn autoplay nicht funktioniert, kann der Besucher einfach auf Play klicken.

Tipp:
Ersetze im Code "musikdateiname.mp3" durch den Pfad Deiner Datei,
z. B. "sounds/birds-and-waterfall.mp3".

Falls Du den Player ausblenden möchtest:
Wenn Du den Audio-Player nicht sichtbar anzeigen möchtest, kannst Du das controls-Attribut weglassen:

HTML
<audio autoplay loop>

→ Der Player wird nicht angezeigt.

Das war's auch schon von mir. 😊
