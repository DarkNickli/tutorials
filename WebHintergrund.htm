Hintergrund gestalten

CSS

Web-Programmierung

Erklärung

1. Hintergrundfarbe

Mit background kannst Du mehrere Hintergrund-Einstellungen zusammenfassen.
Damit kannst Du zum Beispiel eine Hintergrundfarbe, ein Bild oder weitere Eigenschaften festlegen.
Mit background-color bestimmst Du nur die Hintergrundfarbe.

HTML
<!-- BODY-Bereich -->
<body style="background-color:#c00000;">

→ Rote Hintergrundfarbe.

Und beim CSS:

CSS
body {
    background-color: #c00000;
}

→ Rote Hintergrundfarbe.

2. Hintergrundbild

Mit background-image fügst Du ein Hintergrundbild hinzu.

HTML
<!-- BODY-Bereich -->
   <body style="background-image: url('bilder/Dein-Bild.jpg');">

Und beim CSS:

CSS
 body {
       background-image: url('bilder/Dein-Bild.jpg');
      }
/* Trage hier den genauen Pfad zu Deinem Bild ein. */

→ Ersetze im Code "bilder/Dein-Bild.jpg" durch den Pfad Deiner Datei

3. Hintergrund fixieren

Mit background-attachment steuerst Du, ob der Hintergrund scrollt oder fixiert ist.

HTML
<!-- BODY-Bereich -->
 <body style="background-image: url('bilder/Dein-Bild.jpg'); background-attachment: scroll;">

background-image setzt das Hintergrundbild,
background-attachment: scroll sorgt dafür, dass das Hintergrundbild beim Scrollen mit der Seite mitbewegt wird.

Und beim CSS:

CSS
   body {
    background-image: url('bilder/Dein-Bild.jpg');
    background-attachment: fixed;
}

Mit background-attachment: fixed; bleibt das Hintergrundbild beim Scrollen fixiert.

4. Hintergrund wiederholen

Mit background-repeat legst Du fest, ob und wie sich das Hintergrundbild wiederholt.

HTML
<!-- BODY-Bereich -->
   <body style="background-image: url('bilder/Dein-Bild.jpg'); background-repeat: no-repeat;">

Und beim CSS:

CSS
body {
    background-image: url('bilder/Dein-Bild.jpg');
    background-repeat: no-repeat;
}

no-repeat → Keine Wiederholung.
repeat → Bild wird horizontal und vertikal wiederholt.
repeat-x → Bild wird nur horizontal wiederholt.
repeat-y → Bild wird nur vertikal wiederholt.

5. Hintergrund positionieren

Mit background-position bestimmst Du, an welcher Stelle das Hintergrundbild angezeigt wird.
Denn background-position kannst Du auch verwenden, wenn das Hintergrundbild nicht wiederholt wird.

HTML
<!-- BODY-Bereich -->
<body style="background-image: url('bilder/Dein-Bild.jpg'); 
background-repeat: no-repeat; 
background-position: 50% 50%;">

Und beim CSS:

CSS
body {
    background-image: url('bilder/Dein-Bild.jpg');
    background-repeat: no-repeat;
    background-position: 50% 50%;
}

center → Bild wird mittig ausgerichtet.
right → Bild wird rechts ausgerichtet.
left → Bild wird links ausgerichtet.
top → Bild wird oben ausgerichtet.
bottom → Bild wird unten ausgerichtet.
Prozent → Mit zwei Prozentwerten bestimmst Du die horizontale und vertikale Position des Hintergrundbildes.

Beispiel:
background-position: 50% 50%; → Das Bild steht mittig.
Oder:
background-position: 0% 0%; → Das Bild steht oben links.
Oder:
background-position: 100% 100%; → Das Bild steht unten rechts.

CSS wird am besten in einer eigenen Datei oder im <style>-Bereich der HTML-Datei eingefügt,
anstatt die Styles direkt im HTML-Tag mit dem style-Attribut festzulegen.

Dadurch bleibt der Code übersichtlicher und leichter zu bearbeiten.

Beispiel:
CSS kann im <style>-Bereich innerhalb des <head>-Bereichs der HTML-Datei eingefügt werden.

HTML
<head>
<style>
body {
font-family: Verdana;
font-size: 13px;
background-image:url('bilder/Dein-Bild.jpg');
background-repeat:no-repeat;
background-position:50% 50%;
}
</style>
</head>

<body>

Oder in einer externen CSS-Datei:

CSS
body {
    font-family: Verdana;
    font-size: 13px;
    background-image: url('bilder/Dein-Bild.jpg');
    background-repeat: no-repeat;
    background-position: 50% 50%;
}
