Erklärung

1. Verbindung von HTML und CSS

So benutzt Du den Stil direkt im HTML:

HTML
<h2 class="text-effect">Willkommen</h2>

class="..." verbindest Du das HTML-Element mit dem passenden CSS-Stil aus Deiner style.css.
Der Browser sucht dann im Stylesheet nach der entsprechenden CSS-Klasse (z. B. .text-effect)
und übernimmt automatisch alle definierten Eigenschaften wie:
•Schriftfarbe
•Schriftgröße
•Schatteneffekte
•Schriftart

Dadurch sieht der Text genau so aus, wie Du ihn gestaltet hast.

1. Beispiel Effekt

Letterpress-Effekt

Der Text wirkt, als wäre er in den Hintergrund eingedrückt.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
color: #b9b9b9; 		/* Schriftfarbe Hellgrau */
text-shadow: 			/* Textschatten mit zwei Schatten */
1px 1px #ffffff, 		/* weißer Schatten rechts unten */
-1px -1px #313131; 		/* dunkler Schatten links oben */
}

2. Beispiel Effekt

Emboss-Effekt

Der Text wirkt plastisch aus dem Hintergrund herausgehoben.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
color: #b9b9b9; 		/* Schriftfarbe Hellgrau */
text-shadow: 			/* Textschatten mit zwei Schatten */
-1px -1px #ffffff, 		/* weißer Schatten links oben */
1px 1px #313131; 		/* dunkler Schatten rechts unten */
}

3. Beispiel Effekt

Klassischer Schatten-Effekt

Ein einfacher, weicher Schatten für bessere Lesbarkeit.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
color: #000000; 		/* Schriftfarbe Schwarz */
text-shadow: #000000 -0.1em 0.1em 0.2em; /* Schwarzer Schatten, leicht versetzt mit Weichzeichnung */
}

4. Beispiel Effekt

Glühender Effekt

Der Text erhält ein neongrünes Leuchten.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
background: #000000; 		/* Schwarzer Hintergrund */
color: #00ff0f; 		/* Schriftfarbe Neongrün */
text-shadow: 			/* Grüner Leuchteffekt als Schatten */
0 0 0.2em #00ff0f, 		/* erster grüner Leuchteffekt */
0 0 0.2em #00ff0f; 		/* zweiter grüner Leuchteffekt */
}

5. Beispiel Effekt

Über- und unterstrichener Text

Dekorationslinien oberhalb und unterhalb des Textes.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
text-decoration: overline underline; /* Text mit Überstrich und Unterstrich */
}

6. Beispiel Effekt

Anfangsbuchstabe hervorheben

Mithilfe des Pseudo-Elements :first-letter lässt sich der erste Buchstabe einer Überschrift separat gestalten.

CSS
 h1 {
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-family: 'Playfair Display', serif; /* Schriftart Playfair Display, alternativ Serif */
color: #bddaf8; 		/* Hellblau Schriftfarbe */
font-style: italic; 		/* Kursivschrift */
text-shadow: #72abaa 1px 1px; 	/* Schatten in Türkis, 1px rechts unten versetzt */
}

h1:first-letter {
font-size: 50px; 		/* Erste Buchstabe größer (50 Pixel) */
letter-spacing: 5px; 		/* Abstand zwischen Buchstaben vergrößert */
color: #f5d3f8; 		/* Hellrosa Farbe */
font-family: 'Great Vibes', cursive; /* Andere Schriftart für den ersten Buchstaben */
text-shadow: #d53ada 1px 1px; 	/* Schatten in Pink, 1px rechts unten versetzt */
}

Hinweis zu Google Fonts:
Damit die Schriftarten Playfair Display und Great Vibes im Browser korrekt dargestellt werden, musst Du
die Schriftarten im <head>-Bereich Deiner HTML-Datei einbinden:

CSS
 <link href="https://fonts.googleapis.com/css2?family=Great+Vibes&family=Playfair+Display:ital@1&display=swap" rel="stylesheet">

7. Beispiel Effekt

Text im Rahmen

Erzeugt eine äußere Umrandung des Elements.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
outline: 5px double black; 	/* Doppellinien-Rahmen außen, 5 Pixel dick, schwarz */
}

8. Beispiel Effekt

Text mit mehreren Schatten

Erzeugt einen bunten 3D-Effekt durch drei versetzte Schattenebenen.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
color: #000000; 		/* Schriftfarbe Schwarz */
text-shadow: 			/* Mehrfacher bunter Schatten für 3D-Effekt */
0.2em 0.5em 0.1em #11b4cf, 	/* hellblauer Schatten leicht rechts unten */
-0.3em 0.1em 0.1em #11cf18, 	/* grüner Schatten leicht links unten */
0.4em -0.3em 0.1em #6c136f; 	/* lila Schatten leicht rechts oben */
}

9. Beispiel Effekt

Text in Großbuchstaben

Egal wie der Text im HTML getippt wurde: Er wird komplett in VERSALIEN (Großbuchstaben) dargestellt.

HTML
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
text-transform: uppercase; 	/* Text wird komplett in Großbuchstaben umgewandelt */
}

10. Beispiel Effekt

Text mit Kontur (Stroke-Effekt)

Durch einen minimalen Schatten in alle vier Richtungen entsteht eine Textkontur.

CSS
.text-effect {
font-family: Georgia; 		/* Schriftart Georgia */
font-size: 35px; 		/* Schriftgröße 35 Pixel */
font-weight: bold; 		/* Fettschrift */
font-style: italic; 		/* Kursivschrift */
color: #fff; 			/* Weiße Schriftfarbe */
text-shadow: 			/* Schwarzer Schatten rundum für Kontur-Effekt */
0 -1px #000, 			/* Schatten oben */
1px 0 #000, 			/* Schatten rechts */
0 1px #000, 			/* Schatten unten */
-1px 0 #000; 			/* Schatten links */
}

Mit diesen Text-Effekten hast Du gelernt, wie Schatten und Styles Texte optisch verbessern und besser lesbar machen.
