Bildlaufleiste erstellen

HTML


Web-Programmierung

Kopiere einfach den folgenden HTML-Code und füge ihn in den <body>-Bereich Deiner Webseite ein.

html
<div class="scroll-container">
<div class="scroll-content">
    <img src="Dein Bild.jpg" alt="Bild 1">
    <img src="Dein Bild.jpg" alt="Bild 2">
    <img src="Dein Bild.jpg" alt="Bild 3">
    <img src="Dein Bild.jpg" alt="Bild 4">

<!-- Die Bilder werden doppelt verwendet, damit das Scrollen nahtlos wirkt. -->

    <img src="Dein Bild.jpg" alt="Bild 1">
    <img src="Dein Bild.jpg" alt="Bild 2">
    <img src="Dein Bild.jpg" alt="Bild 3">
    <img src="Dein Bild.jpg" alt="Bild 4">
</div>
</div>

Kopiere den Stil-Code in Deine CSS-Datei.
Du kannst die Farben anschließend an Dein Design anpassen.

css
.scroll-container {
    margin: 0 auto;
    width: 250px;
    height: 250px;
    overflow: hidden;
    position: relative;
    border: 1px solid #ccc;
}

.scroll-content {
    display: flex;
    flex-direction: column;
    animation: scrollUp 25s linear infinite;
    align-items: center;
}

.scroll-content:hover {
    animation-play-state: paused;
}

.scroll-content img {
    width: 250px;
    margin-bottom: 20px;
    user-select: none;
    pointer-events: none;
}

@keyframes scrollUp {
    0% {
        transform: translateY(0);
    }
    100% {
        transform: translateY(-50%);
    }
}

Erklärung

CSS
.scroll-container {
    width: 250px;
    height: 250px;
}

Du kannst die width und height ganz nach Deinen Bedürfnissen anpassen.

CSS
.scroll-content img {
    width: 250px;
    margin-bottom: 20px;
}

Alle Bilder bekommen eine Breite von 250 Pixeln und passen damit genau in den Container.
Mit margin-bottom: entsteht unter jedem Bild ein Abstand von 20 Pixeln.
So kleben die Bilder nicht direkt aneinander, sondern stehen mit etwas Abstand untereinander.

HTML
<div class="scroll-container">
    <div class="scroll-content">
        <img src="Dein Bild.jpg" alt="Bild 1">
        <img src="Dein Bild.jpg" alt="Bild 2">

.scroll-container ist die sichtbare Box, die den Scrollbereich begrenzt.
.scroll-content enthält alle Bilder, die animiert nach oben scrollen.
Ersetze Dein Bild.jpg durch den direkten Link zu Deinem Bild.

Hinweis:
Die Bilder sind absichtlich doppelt vorhanden, damit die Animation flüssig und ohne sichtbaren Sprung in einer Endlosschleife läuft.

HTML
.scroll-container {
    border: 1px solid #ccc;
}

1px gibt die Rahmenstärke in Pixeln an.
solid legt den Linienstil des Rahmens fest.
Den Linienstil kannst Du mit Werten wie solid, dashed, dotted ändern.
#ccc → Legt die Farbe des Rahmens fest.

Ich würde nach der Erklärung von .scroll-content noch diesen kleinen Abschnitt ergänzen:

HTML
.scroll-content:hover {
    animation-play-state: paused;
}

→ Wenn Du mit der Maus über die Bildlaufleiste fährst, wird die Animation angehalten.

Das war's auch schon von mir. 😊
