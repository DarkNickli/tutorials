Google Fonts einbinden

HTML

Web-Programmierung

Vorschau, wie Deine Schriftart eingebunden wird.

HTML
<head>
<link href="https://fonts.googleapis.com/css2?family=Caveat:wght@400..700&family=Playwrite+VN+Guides&display=swap" rel="stylesheet">
</head>

<body>
CSS
body {
  font-family: "Playwrite VN Guides", cursive;
  font-weight: 400;
  font-style: normal;
}

Erklärung

１. Google Fonts öffnen:
Gehe auf Google Fonts
２. Schriftart aussuchen:
Suche Dir eine Schrift aus, die Dir gefällt, und wähle die gewünschten Schriftstärken aus, z. B. normal oder fett.
３. Schriftart auswählen:
Klicke auf die gewünschte Schriftart und anschließend auf Get font.
４. Schriftart kopieren:
Klicke auf Get embed code und kopiere den Einbettungscode.
５. Link in HTML einfügen:
Kopiere den Code und setze ihn im <head>-Teil Deiner Webseite ein.

CSS
<link href="https://fonts.googleapis.com/css2?family=Playwrite+VN+Guides&display=swap" rel="stylesheet">

６. CSS schreiben:
In Deiner CSS-Datei kannst Du die Schrift jetzt verwenden, z. B.:

CSS
body {
    font-family: "Playwrite VN Guides", cursive;
    font-weight: 400;
    font-style: normal;
}

Hinweis:
Die Schrift wird von Google Fonts geladen. Dafür muss beim Aufruf Deiner Webseite eine Verbindung zu den Servern von Google Fonts hergestellt werden.
