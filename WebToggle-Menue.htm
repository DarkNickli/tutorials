Web-Programmierung

Kopiere einfach den folgenden HTML-Code und füge ihn in den <body>-Bereich Deiner Webseite ein.

HTML
 <!-- HIER wird der Ein-/Ausklapp-Text eingefügt -->
<span class="toggle-link" onclick="toggle('text1')">
ANZEIGETEXT
</span>

<div id="text1">
DER TEXT ERSCHEINT BEIM ANKLICKEN
</div>
<!-- Restlicher Inhalt Deiner Seite -->

Kopiere den folgenden CSS-Code in Deine CSS-Datei.
Du kannst die Farben anschließend an Dein Design anpassen.

CSS
/* Versteckt den Text standardmäßig beim Laden der Seite. */
 #text1 {
display: none;
margin-top: 10px;
}

 /* Macht den Text als anklickbar erkennbar. */
.toggle-link {
cursor: pointer;
color: blue;
text-decoration: underline;
}

Kopiere einfach das folgende Skript und füge es entweder in den <head>-Bereich oder ganz unten vor dem schließenden
<body>-Tag Deiner Webseite ein.

JavaScript
 <script>
function toggle(controlId) {
var elem = document.getElementById(controlId);

if (elem.style.display === "none" || elem.style.display === "") {
elem.style.display = "block"; // Zeige das Element
} else {
elem.style.display = "none"; // Verstecke das Element
}
}
</script>

Erklärung

１. Was macht dieser HTML-Code?

Der HTML-Code besteht aus zwei wichtigen Elementen:

HTML
<span class="toggle-link" onclick="toggle('text1')">
ANZEIGETEXT
</span>

und

HTML
<div id="text1">
DER TEXT ERSCHEINT BEIM ANKLICKEN
</div>

♦ <span class="toggle-link">
 ▸ Das <span>-Element enthält den Text, auf den der Besucher klicken kann.
▸ Die Klasse toggle-link wird später im CSS verwendet, um das Aussehen des anklickbaren Textes festzulegen.
▸ Mit onclick="toggle('text1')" wird beim Anklicken die JavaScript-Funktion toggle() aufgerufen.
Die Angabe 'text1' teilt JavaScript mit, welcher Textbereich ein- oder ausgeblendet werden soll.

♦ <div id="text1">

HTML
<div id="text1">
DER TEXT ERSCHEINT BEIM ANKLICKEN
</div>

▸ Das <div>-Element enthält den Text, der ein- und ausgeblendet werden soll.
▸ Mit text1 erhält dieser Bereich eine eindeutige ID.
▸ JavaScript verwendet diese ID später, um genau diesen Textbereich zu finden.
Die ID text1 muss deshalb mit der ID im onclick-Befehl übereinstimmen:

JavaScript
onclick="toggle('text1')"
id="text1"

♦ Was kannst Du anpassen?

ANZEIGETEXT
 → Diesen Text sieht der Besucher und kann darauf klicken.

Beispiel:

HTML
<span class="toggle-link" onclick="toggle('text1')">
Mehr Informationen anzeigen
</span>

→ Der Besucher sieht nun:
Mehr Informationen anzeigen
statt:
ANZEIGETEXT

DER TEXT ERSCHEINT BEIM ANKLICKEN

Hier kommt der eigentliche Inhalt hinein, der beim Anklicken angezeigt werden soll.

Beispiel:

HTML
<div id="text1">
Hier findest Du weitere Informationen zu diesem Thema.
</div>

Du kannst dort natürlich auch längere Texte, Bilder oder weitere HTML-Elemente verwenden.

２. CSS-Code

Kopiere den folgenden CSS-Code in Deine CSS-Datei.

CSS
#text1 { display: none; margin-top: 10px; } .toggle-link { cursor: pointer; color: blue; text-decoration: underline; }

Mit CSS bestimmst Du das Aussehen des anklickbaren Textes und des ausgeblendeten Bereichs.

#text1

CSS
#text1 { display: none; margin-top: 10px; }
▸ Die Raute # kennzeichnet einen ID-Selektor.
▸ Damit wird das Element mit der ID text1 angesprochen.

Der CSS-Code gilt also für:

HTML
<div id="text1">
...
</div>

display: none;

CSS
display: none;

▸ Der Textbereich wird zunächst ausgeblendet.
▸ Er nimmt dadurch auf der Webseite keinen Platz ein.
▸ Erst wenn der Besucher auf den Anzeigetext klickt, wird der Bereich durch JavaScript eingeblendet.

margin-top: 10px;

CSS
margin-top: 10px;

▸ Fügt oberhalb des eingeblendeten Textes einen Abstand von 10 Pixeln ein.
▸ Dadurch befindet sich der Text nicht direkt unter dem anklickbaren Anzeigetext.
Du kannst den Abstand natürlich ändern.

Beispiel:

CSS
margin-top: 20px;

Damit wird der Abstand auf 20 Pixel erhöht.

.toggle-link

CSS
.toggle-link { cursor: pointer; color: blue; text-decoration: underline; }

▸ Der Punkt . kennzeichnet einen Klassen-Selektor.
▸ Dieser Stil gilt für alle Elemente, die die Klasse toggle-link besitzen.

In unserem HTML-Code ist das:

HTML
<span class="toggle-link">

cursor: pointer;

CSS
cursor: pointer;

▸ Der Mauszeiger wird beim Überfahren des Textes zur Hand.
▸ Dadurch erkennt der Besucher, dass der Text anklickbar ist.

color: blue;

CSS
color: blue;

▸ Legt die Textfarbe fest.
▸ In unserem Beispiel wird der Text blau dargestellt.
Du kannst natürlich auch einen eigenen Farbwert verwenden.

Beispiel:

CSS
color: #aa8800;

Damit erhält der Text einen goldenen Farbton.

text-decoration: underline;

CSS
text-decoration: underline;

▸ Fügt eine Unterstreichung hinzu.
▸ Dadurch sieht der anklickbare Text optisch wie ein klassischer Link aus.
Wenn Du keine Unterstreichung möchtest, kannst Du schreiben:

CSS
text-decoration: none;

→ Keine Unterstreichung.

Extra: Hover-Effekt

Du kannst dem anklickbaren Text zusätzlich einen kleinen Hover-Effekt geben.

Füge dazu folgenden CSS-Code hinzu:

CSS
.toggle-link:hover { color: darkblue; text-decoration: none; }

Wenn Du mit der Maus über den Text fährst:
 ▸ Die Schrift wird dunkelblau.
▸ Die Unterstreichung verschwindet.
Dadurch bekommt der anklickbare Text einen kleinen zusätzlichen Effekt.


３. JavaScript mit Kommentaren

Jetzt kommt der Teil, der dafür sorgt, dass der Text beim Anklicken ein- und wieder ausgeblendet wird.

Kopiere den folgenden Code und füge ihn entweder in den <head>-Bereich oder ganz unten vor dem schließenden
<body>-Tag Deiner Webseite ein.

JavaScript
<script>

// Die Funktion "toggle" wird beim Anklicken aufgerufen
function toggle(controlId) {

    // Sucht das HTML-Element mit der angegebenen ID
    var elem = document.getElementById(controlId);

    // Prüft, ob das Element gerade ausgeblendet ist
    if (elem.style.display === "none" || elem.style.display === "") {

        // Zeigt das Element an
        elem.style.display = "block";

    } else {

        // Versteckt das Element wieder
        elem.style.display = "none";
    }
}

</script>

Was macht das JavaScript?

Die Funktion toggle() prüft, ob der gewünschte Textbereich gerade ausgeblendet oder eingeblendet ist.

Je nachdem wird der Bereich anschließend sichtbar gemacht oder wieder versteckt.

function toggle(controlId)

JavaScript
function toggle(controlId) {

▸ Erstellt eine Funktion mit dem Namen toggle.
▸ Diese Funktion wird beim Anklicken des Anzeigetextes aufgerufen.
▸ controlId ist eine Variable, die die ID des Textbereichs enthält, der ein- oder ausgeblendet werden soll.

In unserem Beispiel wird die Funktion so aufgerufen:

JavaScript
onclick="toggle('text1')"

Dadurch erhält controlId den Wert text1.

document.getElementById(controlId)

JavaScript
var elem = document.getElementById(controlId);

▸ JavaScript sucht nach einem HTML-Element mit der angegebenen ID.

In unserem Beispiel wird nach dem Element mit der ID text1 gesucht.

JavaScript
id="text1"

Das gefundene Element wird anschließend in der Variable elem gespeichert.

Die if-Abfrage

JavaScript
if (elem.style.display === "none" || elem.style.display === "") {

▸ Hier wird geprüft, ob der Textbereich gerade ausgeblendet ist.
▸ Befindet sich der Bereich auf display: none, soll er eingeblendet werden.
▸ Ist keine direkte Anzeige-Einstellung vorhanden, wird er ebenfalls eingeblendet.

Text einblenden

JavaScript
elem.style.display = "block";

▸ Der ausgeblendete Textbereich wird sichtbar gemacht.
▸ display: block sorgt dafür, dass das <div> wieder als Block-Element angezeigt wird.

Text wieder ausblenden

JavaScript
else { elem.style.display = "none"; }

▸ Wenn der Text bereits sichtbar ist, wird er wieder ausgeblendet.
▸ display: none entfernt den Bereich wieder aus der sichtbaren Darstellung.

Durch erneutes Anklicken kann der Besucher den Text wieder anzeigen.

Mehrere Toggle-Bereiche verwenden

Du kannst auf Deiner Webseite natürlich auch mehrere Toggle-Bereiche verwenden.

Wichtig ist dabei, dass jeder Bereich eine eigene ID bekommt.

Beispiel:

HTML
<span class="toggle-link" onclick="toggle('text1')">
   Mehr Informationen
</span>

<div id="text1">
  Hier steht der erste Text.
</div>

<span class="toggle-link" onclick="toggle('text2')">
   Weitere Informationen </span>
   
<div id="text2">
   Hier steht der zweite Text.
  </div>

Die Zuordnung muss dabei immer stimmen:

JavaScript
onclick="toggle('text1')"

gehört zu:

JavaScript
id="text1"

und:

JavaScript
onclick="toggle('text2')"

gehört zu:

JavaScript
id="text2"

Du kannst die IDs beispielsweise auch text3, text4, text5 usw. nennen.

Wichtig: Jede ID darf auf einer Webseite nur einmal vorkommen.
