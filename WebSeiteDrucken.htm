1. Einfacher Druckbutton für Deine Webseite



Mit diesem Button können Besucher die Seite direkt drucken.

HTML
<input type="button" value="Seite drucken" onclick="window.print()"/>

Tipp:
Füge den Code an der Stelle ein, an der der Button erscheinen soll, z. B. am Ende Deiner Seite oder bei einem bestimmten Inhalt.

2. Druckbutton mit CSS-Stil



Kopiere den folgenden CSS-Code in Deine externe CSS-Datei.
Du kannst die Farben anschließend an Dein Design anpassen.

CSS
.print-button {
background-color: #b0acb0;
color: #1a0c1a;
border: 1px solid #d4af37;
padding: 10px 20px;
font-size: 16px;
font-weight: bold;
border-radius: 5px;
cursor: pointer;
box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
transition: all 0.3s ease;
}

.print-button:hover {
background-color: #7d6d7d;
color: #ffffff;
box-shadow: 0 6px 20px rgba(0, 0, 0, 0.25);
transform: scale(1.03);
}
CSS-Eigenschaft Funktion
background-color: #b0acb0; Legt die Hintergrundfarbe des Buttons fest.
color: #1a0c1a; Bestimmt die Schriftfarbe.
border: 1px solid #d4af37; Fügt einen goldfarbenen Rahmen hinzu.
padding: 10px 20px; Gibt dem Button innen mehr Platz: links/rechts 20px, oben/unten 10px.
font-size: 16px; Setzt die Schriftgröße.
font-weight: bold; Macht den Text fett.
border-radius: 5px; Rundet die Ecken des Buttons ab.
box-shadow: 0 2px 5px rgba(0,0,0,0.1); Fügt dem Button einen dezenten Schatten hinzu.
transition: all 0.3s ease; Sorgt für einen sanften Übergang bei Änderungen des Buttons.
transform: scale(1.03);
 Vergrößert den Button beim Darüberfahren leicht.

Kopiere den Code einfach an die Stelle, an der der Button erscheinen soll.

HTML
<input type="button" class="print-button" value="Seite drucken" onclick="window.print()"/>
Bereich Bedeutung
input type="button" Erstellt einen klickbaren Button.
onclick="window.print()" Öffnet beim Klick den Druckdialog des Browsers.
.print-button { ... } Die CSS-Klasse bestimmt das Aussehen des Buttons,
z. B. Farben, Rundungen und Schatten.
value="Seite drucken" Hier steht der Text, der auf dem Button angezeigt wird.
Er kann nach Wunsch geändert werden,
z. B. Druck starten oder Jetzt drucken.

3. Drucker-Grafik zum Klicken

Mit dieser Drucker-Grafik kann der Druck per Klick gestartet werden.

Einfach an die Stelle kopieren, an der der Button erscheinen soll.

HTML
<button onclick="window.print()" class="print-icon" aria-label="Seite drucken">
   <img src="Bilder/icon00.png" alt="Drucker-Icon" width="32" height="32">
</button>

Passe den Pfad im src-Attribut an:

HTML
<img src="Bilder/icon00.png" alt="Drucker-Icon" width="32" height="32">

Hinweis
Achte darauf, dass das Bild icon00.png im Ordner Bilder liegt.
Passe den Pfad im src-Attribut an, falls sich Dein Bild in einem anderen Ordner befindet.

Füge diesen CSS-Code in Deine externe CSS-Datei ein (z. B. style.css).

CSS
.print-icon {
    background: none;
    border: none;
    padding: 5px;
    cursor: pointer;
    transition: transform 0.2s ease;
}

.print-icon:hover {
    transform: scale(1.1);
}
CSS-Eigenschaft Funktion
background: none; Kein Hintergrund, das Bild steht frei.
border: none; Kein Rahmen um den Button.
padding: 5px; Kleiner Abstand rund ums Bild.
cursor: pointer; Beim Darüberfahren wird der Mauszeiger zur Hand.
transition: transform 0.2s ease; Sorgt für einen sanften Übergang beim Hover-Effekt.
transform: scale(1.1); Vergrößert das Bild beim Darüberfahren leicht.
