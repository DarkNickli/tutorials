Web-Programmierung

Kopiere einfach das folgende Skript und füge es in den <body>-Bereich Deiner Webseite.

HTML

<div class="newsbox">

  <!-- Newsbox-Grafik -->
  <img
    class="newsbox-bg"
    src="Bilder/Newsbox.jpg"
    alt="Newsbox">

  <!-- Inhaltsbereich -->
  <div class="in-halt">

    <!-- Text -->
    <p><u>✦Beispiel✦</u></p>

    <p>Tutorials überarbeitet. ✓</p>
    <p>Layout bearbeitet. ✓</p>
    <p>Inhalte überarbeitet. ✓</p>
    <p>Sign-Tutorial geschrieben. ✓</p>
    <p>Filter erstellt. ✓</p>

    <p>✦Viel Spaß mit der Box✦</p>

    <p>
      <a
  href="https://phantasygraphics.blogspot.com"
  target="_blank"
  rel="noopener"
  class="credits">

        Newsbox by DarkNickli
      </a>
    </p>

    <!-- Text Ende -->
</div>
</div>

Kopiere den Stil-Code in Deine CSS-Datei.
Du kannst die Farben anschließend an Dein Design anpassen.

CSS
/* Newsbox */
.newsbox {
  width: min(500px, 100%);
  aspect-ratio: 500 / 300;
  margin: 0 auto;
  position: relative;
}

/* Newsbox-Grafik */
.newsbox-bg {
  width: 100%;
  height: 100%;
  display: block;
}

/* Inhaltsbereich */
.in-halt {
  position: absolute;
  /*
     Originalgröße:
     Breite: 500 px
     Höhe: 300 px

     Position:
     oben: 66 px
     links: 14 px
  */
  left: 2.8%;
  top: 22.1%;
  width: 55%;
  height: 71%;
  box-sizing: border-box;
  padding: 5px 13px;
  background-color: rgba(23, 17, 8, 0.35);
  color: #d1cfcc;
  font-family: "Lucida Sans", Verdana, sans-serif;
  font-weight: bold;
  text-align: center;
  overflow-y: auto;
  scrollbar-width: thin;
  scrollbar-color: #d1cfcc transparent;
}

/* Absätze */
.in-halt p {
  margin-top: 1em;
  margin-bottom: 1em;
}

/* Scrollbar Chrome / Edge / Safari */
.in-halt::-webkit-scrollbar {
  width: 8px;
}

.in-halt::-webkit-scrollbar-track {
  background: transparent;
}

.in-halt::-webkit-scrollbar-thumb {
  background-color: #d1cfcc;
  border-radius: 4px;
}

/* Credits */

.credits {
  margin-top: 10px;
  font-size: 7pt;
  font-weight: lighter;
  color: #d1cfcc;
  text-decoration: none;
  transition: all 0.3s ease;
}

.credits:hover {
  text-decoration: none;
  letter-spacing: 1px;
  color: #b1a79e;
}

Erklärung

1. Die Newsbox

HTML
  <div class="newsbox">

  <!-- Newsbox-Grafik -->
  <img
    class="newsbox-bg"
    src="Bilder/Newsbox.jpg"
    alt="Newsbox">

  <!-- Inhaltsbereich -->
  <div class="in-halt">

    <!-- Text -->

...
    <!-- Text Ende -->

</div>
</div>

Anpassungen:
 <div class="newsbox"> → Erstellt den äußeren Bereich der Newsbox.
<img class="newsbox-bg"> → Fügt die Newsbox-Grafik ein.
<div class="in-halt"> → Enthält den News-Inhalt und bildet den scrollbaren Bereich.
<p>...</p> → Erstellt einen News-Eintrag. Den Text kannst Du durch Deine eigene Nachricht ersetzen.
<a ...> → Erstellt den Link am unteren Ende der Newsbox. Passe die Adresse und den Linktext nach Deinen Wünschen an.

Tipp:
Du kannst die Beispieltexte und Symbole jederzeit durch Deine eigenen Inhalte ersetzen. Die HTML-Struktur sollte dabei erhalten bleiben, damit die Newsbox korrekt funktioniert.

Passe den Pfad im src-Attribut an:

HTML
  <!-- Newsbox-Grafik -->
  <img
    class="newsbox-bg"
    src="Bilder/Newsbox.jpg"
    alt="Newsbox">

Hinweis
Achte darauf, dass sich das Bild Newsbox.jpg im Ordner Bilder befindet.
Passe den Pfad im src-Attribut an, falls sich Dein Bild in einem anderen Ordner befindet.


2. Die Newsbox CSS-Datei

Das ist der äußere Bereich der Newsbox.

CSS
.newsbox { 
  width: min(500px, 100%); 
  aspect-ratio: 500 / 300; 
  margin: 0 auto; 
  position: relative; 
}

Anpassungen:
 width: min(500px, 100%); → Legt die maximale Breite der Newsbox fest.

Die Newsbox wird maximal 500 Pixel breit. Ist auf der Webseite weniger Platz vorhanden, wird sie automatisch kleiner.

aspect-ratio: 500 / 300; → Behält das Seitenverhältnis der Newsbox-Grafik bei.

margin: 0 auto; → Zentriert die Newsbox horizontal.

position: relative; → Ermöglicht die genaue Positionierung des Inhaltsbereichs innerhalb der Newsbox.

Wichtig:
Die ursprüngliche Grafik hat eine Größe von 500 × 300 Pixel.
Diese Größe dient als Grundlage für die automatische Skalierung.
Ist beispielsweise nur eine Breite von 400 Pixeln verfügbar, wird die Newsbox automatisch proportional verkleinert.
Du musst dafür keine Größe von Hand anpassen.


3. Die Newsbox-Grafik

CSS
.newsbox-bg { 
  width: 100%; 
  height: 100%; 
  display: block; 
}

Anpassungen:
 width: 100%; → Die Grafik nimmt immer die gesamte verfügbare Breite der Newsbox ein.
height: 100%; → Die Höhe wird entsprechend der Größe der Newsbox angepasst.
display: block; → Verhindert einen zusätzlichen kleinen Abstand, der bei Bildern entstehen kann.

Wichtig:
Die Grafik ist jetzt kein Hintergrundbild mehr, sondern ein eigenes <img>-Element.
Das hat einen wichtigen Vorteil:
Der Inhaltsbereich kann sich direkt an der Größe der Grafik orientieren.
Dadurch kann die gesamte Newsbox proportional mitskalieren.


4. Der Inhaltsbereich

CSS
.in-halt { 
  position: absolute; 
  left: 2.8%; 
  top: 22.1%; 
  width: 55%; 
  height: 71%; 
  box-sizing: border-box; 
  padding: 5px 13px; 
  background-color: rgba(23, 17, 8, 0.35); 
  color: #d1cfcc; 
  font-family: "Lucida Sans", Verdana, sans-serif; 
  font-weight: bold; 
  text-align: center; 
  overflow-y: auto; 
}

Der Inhaltsbereich wird prozentual zur Newsbox positioniert und dimensioniert.

Anpassungen:
 position: absolute; → Positioniert den Inhaltsbereich innerhalb der Newsbox.
left: 2.8%; → Legt die horizontale Position des Inhaltsbereichs innerhalb der Grafik fest.
top: 22.1%; → Legt die Position des Inhaltsbereichs von oben fest.
width: 55%; → Legt die Breite des Inhaltsbereichs proportional zur Grafik fest.
height: 71%; → Legt die Höhe des Inhaltsbereichs proportional zur Grafik fest.
box-sizing: border-box; → Bezieht den Innenabstand in die angegebene Breite und Höhe mit ein.
background-color: rgba(23, 17, 8, 0.35); → Gibt dem Inhaltsbereich einen halbtransparenten dunklen Hintergrund.
color: → Legt die Schriftfarbe fest.
font-weight: → Legt die Schriftstärke fest.
text-align: → Richtet den Text horizontal aus.
overflow-y: auto; → Zeigt einen vertikalen Scrollbalken an, sobald der Inhalt nicht mehr vollständig in
den Inhaltsbereich passt.

Der besondere Vorteil
Da left, top, width und height prozentual angegeben sind, verändert sich der Inhaltsbereich zusammen mit der Grafik.
Die Position muss deshalb bei einer kleineren Darstellung nicht von Hand angepasst werden.


5. Die Scrollbar

CSS
.in-halt {
   scrollbar-width: thin; 
   scrollbar-color: #d1cfcc transparent; 
  } 
  
.in-halt::-webkit-scrollbar {
   width: 8px; 
  } 
    
.in-halt::-webkit-scrollbar-track {
   background: transparent; 
  } 
      
.in-halt::-webkit-scrollbar-thumb {
   background-color: #d1cfcc; 
   border-radius: 4px; 
  }

Anpassungen:
 scrollbar-width: thin; → Legt einen dünnen Scrollbalken für Firefox fest.
scrollbar-color: → Legt hier die Farbe des Scrollbalken-Griffs fest.
::-webkit-scrollbar → Ermöglicht die Gestaltung der Scrollbar in Chrome, Edge und Safari.
width: → Legt die Breite des Scrollbalkens fest.
background-color: → Legt die Farbe des Scrollbalken-Griffs fest.
background: transparent; → Macht den Hintergrund der Scrollbar-Spur durchsichtig.
border-radius: → Rundet den Scrollbalken ab.


6. Credits

CSS
.credits { 
  margin-top: 10px; 
  font-size: 7pt; 
  font-weight: lighter; 
  color: #d1cfcc; 
  text-decoration: none; 
  transition: all 0.3s ease; 
} 

.credits:hover { 
  text-decoration: none; 
  letter-spacing: 1px; 
  color: #b1a79e; 
}

Anpassungen:
 margin-top: → Legt den Abstand nach oben fest.
font-size: → Legt die Schriftgröße fest.
font-weight: lighter; → Stellt den Credits-Text dünner als den übrigen Newsbox-Text dar.
color: → Legt die Schriftfarbe fest.
text-decoration: → Entfernt die Unterstreichung des Links.
transition: → Sorgt für einen weichen Übergang beim Hover-Effekt.
.credits:hover → Ändert das Aussehen des Links, wenn Du mit der Maus darüberfährst.
letter-spacing: → Vergrößert beim Darüberfahren leicht den Abstand zwischen den Buchstaben.

HTML
  <a
  href="https://phantasygraphics.blogspot.com"
  target="_blank"
  rel="noopener"
  class="credits">

target="_blank" → Öffnet den Link in einem neuen Browser-Tab.
rel="noopener" → Verhindert, dass die neu geöffnete Seite über das ursprüngliche Fenster zugreifen kann.


7. Automatische Anpassung

Die Newsbox wurde so aufgebaut, dass sie sich automatisch an die verfügbare Breite der Webseite anpasst.

Die Originalgröße beträgt:
500 × 300 Pixel
Ist genügend Platz vorhanden, wird die Newsbox in ihrer Originalgröße dargestellt.
Ist weniger Platz vorhanden, wird sie automatisch verkleinert.
Dabei bleiben Grafik und Inhaltsbereich proportional zueinander.
Du musst daher keine Werte für die Größe oder Position des Inhaltsbereichs anpassen.

Beispiel
Bei ausreichend Platz:
500 × 300 Pixel
Bei einer verfügbaren Breite von 400 Pixeln:
400 × ca. 240 Pixel
Bei einer verfügbaren Breite von 300 Pixeln:
300 × ca. 180 Pixel
Die Newsbox passt sich somit automatisch an Desktop, Tablet und kleinere Bildschirme an.

Tipp:
Gerade wenn Du die Newsbox anderen Bastlern zur Verfügung stellst, ist diese Variante praktisch.
